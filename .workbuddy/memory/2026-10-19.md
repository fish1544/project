## 中文乱码修复（同日追加，commit 14e55f4）

**症状**：Web/APK 里中文全显示方块——Godot 默认字体 Open Sans 无中文字形。

**方案**：字体子集化 + 项目主题全局启用：
1. `tools/art/collect_chars.py` 扫描工程 .gd/.tscn 收集实际用到的 467 个字符
2. fontTools.varLib.instancer 把 Noto Sans SC VF pin 成 Regular（wght=400）
3. fontTools.subset 按字符表子集化 → `assets/fonts/noto_sc_cn.ttf`（**111KB**，原 17.7MB）
4. project.godot 加 `[gui] theme/custom_font="res://assets/fonts/noto_sc_cn.ttf"`，LabelSettings/Button 的 font_size override 不影响字体继承
5. 字体构建已集成进 build.sh（collect + instance + subset 三步，缺字体源/包时自动跳过不阻断）
6. venv 路径：`C:/Users/zhy/.workbuddy/binaries/python/envs/default/Scripts/python.exe`（注意是 Scripts 不是 bin；fonttools 模块入口大小写敏感：`python -m fontTools.subset`）

**坑**：新加入 .ttf 后第一次 `--import` 会报 "No loader found"，必须跑第二次 import 生成 .import 元数据后才被识别为 FontFile。

## 自定义开屏加载页（同日追加，commit be0e0c2）

**需求**：Godot Web 原生启动页（黑底+细进度条）太丑，换成游戏自己设计的开屏。

**方案**：`boot.html` 自定义 HTML shell（export_presets.cfg: `html/custom_html_shell="res://boot.html"`）
- 默认 shell 模板在导出模板 zip 内：`%APPDATA%/Godot/export_templates/4.7.2.stable/web_release.zip` → `godot.html`
- 真实进度 API：`engine.startGame({'onProgress': (current, total) => {}})`（默认 shell 同款），占位符 $GODOT_PROJECT_NAME / $GODOT_URL / $GODOT_SPLASH / $GODOT_CONFIG / $GODOT_THREADS_ENABLED / $GODOT_HEAD_INCLUDE
- 设计：深蓝紫夜空渐变 + CSS 星点闪烁 + 流星动画 + 浮动 pixel Logo（$GODOT_SPLASH=index.png）+ 金色像素进度条（条纹+流光）+ 分阶段文案（唤醒引擎/下载运行时/装载星陨之夜…）+ 完成淡出
- 本地验证：python -m http.server + curl 200/title 替换无残留

**坑**：export_presets.cfg 里 `html/custom_html_shell` 键重复时 ConfigFile 取最后一个（空值→回退默认 shell），Edit 时注意别留重复行。

**关于慢的实话**：index.wasm 39.5MB 是 Godot 4 release 引擎体积，GitHub Pages 对 .wasm/.pck 不做 brotli/gzip 压缩（仅 html/js/css/svg），首次加载慢是平台限制；二次访问有缓存。自定义开屏解决感知体验；要质变得换 Cloudflare 等支持 wasm br 压缩的托管。
