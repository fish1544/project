## 踩坑记录

1. Android 导出报 "Unable to open Android build-tools" → 编辑器设置里 SDK/JDK 路径是默认空路径，需改指向 `D:/dev-tools/*`。
2. Android 导出报 "需要 ETC2/ASTC" → project.godot 的 `[rendering]` 加 `textures/vram_compression/import_etc2_astc=true`。
3. "No project icon specified" → project.godot 加 `config/icon`，export_presets.cfg 的 launcher_icons/main_192x192、adaptive_foreground/background_432x432 填资源路径即可。
4. **push 网络**：git 全局代理 127.0.0.1:7897 已失效；HTTPS 直连 git 客户端握手被中断（curl 能通、git 不通）。可靠办法：SSH 22 端口通，用 `gh api -X POST repos/fish1544/project/keys -f key=@公钥 -F read_only=false` 注册**仓库部署密钥**，`GIT_SSH_COMMAND="ssh -i <私钥> -o IdentitiesOnly=yes" git push git@github.com:fish1544/project.git main`，推完 gh api DELETE 掉密钥。gh CLI 已登录（keyring）。
