## 中文乱码修复（同日追加，commit 14e55f4）

**症状**：Web/APK 里中文全显示方块——Godot 默认字体 Open Sans 无中文字形。

**方案**：字体子集化 + 项目主题全局启用：
1. `tools/art/collect_chars.py` 扫描工程 .gd/.tscn 收集实际用到的 467 个字符
2. fontTools.varLib.instancer 把 Noto Sans SC VF pin 成 Regular（wght=400）
3. fontTools.subset 按字符表子集化 → `assets/fonts/noto_sc_cn.ttf`（**111KB**，原 17.7MB）
4. project.godot 加 `[gui] theme/custom_font="res://assets/fonts/noto_sc_cn.ttf"`，LabelSettings/Button 的 font_size override 不影响字体继承
5. 字体构建已集成进 build.sh（collect + instance + subset 三步，缺字体源/包时自动跳过不阻断）
6. venv 路径：`C:/Users/zhy/.workbuddy/binaries/python/envs/default/Scripts/python.exe`（注意是 Scripts 不是 bin；fonttools 模块入口大小写敏感：`python -m fontTools.subset`）

**坑**：新加入 .ttf 后第一次 `--import` 会报 "No loader found"，必须跑第二次 import 生成 .import 元数据后才被识别为 FontFile。
