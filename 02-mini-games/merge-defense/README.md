# 合成防线 · Merge Defense

「合成 + 防守」最小可玩版本。`ruleset_id = MERGE-DEF-001-v1`，默认种子 `20261107`。

线上入口：<https://fish1544.github.io/project/02-mini-games/merge-defense/>

## 运行

- 双击 `index.html` 即可，无依赖、无构建、无外部资源。
- 页面自检：`index.html?selftest` → 末行输出 `TEST PASS`（33 项规则断言）。
- Node 侧校验（可选）：
  - `node -e "const E=require('./js/engine.js'); const r=E.selftest(); console.log(r.fails, r.results.length)"`
  - `node tests/balance.mjs competent` 或 `node tests/balance.mjs sloppy`（固定种子的逐波数值模拟）
  - `node tests/browser-test.mjs`（Chrome headless + CDP 走查 21 项，需要本机 Chrome；设 `GAME_URL` 可直接验收线上入口）

## 要验证的假设

> 玩家会在“继续攒同类换槽位”与“把火力堆在单路”之间做取舍，而不是把金币平均撒在两条路上。

- 玩家任务：守住 10 波，基地 15 点血被打穿即失败。
- 支持假设的信号：合成次数上升、阵容出现等级差（L5 与 L1 并存）、两路 DPS 明显不相等、卖出（回收 50%）被主动使用。
- 护栏信号：如果玩家只是无脑买最贵的单位就能通关，说明槽位压力不足，取舍不成立。
- 本 Demo 不负责证明：长期成长曲线、商业化、真人付费意愿。

## 规则（与 `js/engine.js` 的 `CFG` 同源）

### 阶段

| 阶段 | 时长 | 可做的事 |
|---|---|---|
| 准备 prep | 30 秒 | 买 / 刷新商店 / 移动 / 合成 / 卖出；倒计时归零自动开战，也可按 `F` 提前开战 |
| 战斗 combat | 最多 60 秒 | 全自动，玩家只能看（调试面板可开“战斗中允许合成/移动”） |
| 结算 settle | 手动 | 显示击杀 / 漏怪 / 承伤 / 收入 / 下一波预告 |

- 敌人全清 → 提前结束;存活时间每剩 10 秒 +1 金币（上限 3）。
- 60 秒仍有敌人 → 存活敌人各结算一次基地伤害 → 判本波超时。
- **最终波（第 10 波）必须在 60 秒内清空，否则直接判负。**

### 合成

- 两个**同类型、同等级**单位 → 目标升 1 级，来源消失，等级上限 L5。
- 每升 1 级：伤害 ×2、生命 ×2，攻速/射程/减速等不变，合成后满血。
- 合成本身**不增加总火力**（两个 L1 合成一个 L2 = 原来总火力）。价值全部来自**槽位压缩**：2 格变 1 格。
- 卖出回收累计投入的 50%（累计投入 = `cost × 2^(level-1)`，L1 弓手买 2 金、卖回 1 金）。

### 单位（L1 数值）

| 单位 | 价格 | L1 战力 | 特性 |
|---|---|---|---|
| 弓手 archer | 2 金 | 10.0 DPS（6 伤 / 0.6 秒，射程 300） | 单体速射，最稳的持续输出 |
| 火炮 cannon | 3 金 | 8.6 DPS（12 伤 / 1.4 秒，射程 260，溅射 70） | 同路最多同时打 3 个 |
| 冰霜 frost | 3 金 | 5.0 DPS（4 伤 / 0.8 秒，射程 240） | 命中减速 40%，持续 1.2 秒（取较大值，不叠加） |
| 壁垒 bulwark | 2 金 | 60 HP，阻挡 30px | 把同路敌人钳在自己身前挨打，会被围攻打死并从棋盘消失 |

- 商店 4 件、权重 弓手 40 / 火炮 25 / 冰霜 22 / 壁垒 13，刷新 1 金。
- 棋盘 10 格 = 2 路 × 5 格；**单位只作用于自己那一路**，做不了跨路支援。

### 经济

- 起始 10 金；击杀掉金；清波奖励 `2 + 波次号`；提前结束每剩 10 秒 +1（上限 3）。
- 升级不额外花钱，唯一持续支出是买单位与刷新。

## 已验证

- 引擎规则自检 33/33 通过（浏览器 `?selftest` 与 Node 同源）。
- 真实浏览器走查 21/21 通过（`tests/browser-test.mjs`，Chrome headless）：首次加载、开始、购买、合成、开战、结算、下一轮、失败、重开、规则浮层、窄屏 414px 不裁切、画布像素非空。截图见 `_shots/`。
- 数值模拟（`tests/balance.mjs`，种子 11 / 20261107 / 777）：
  - `competent`（懂两路覆盖、会攒合同类）在 2/3 种子通关，第 10 波 58 秒级惊险清空；
  - `sloppy`（只管堆一路）多数在末波超时判负。
  - 难度带 = 读得懂取舍险胜、不管覆盖者惜败。
