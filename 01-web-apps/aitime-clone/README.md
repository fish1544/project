# 爱时间 · 复刻版（aitime-clone）

按用户上传的手机录屏（720×1584 / 355s）逐帧还原「爱时间 v9.9.14」（作者：林森）安卓 App 的**纯前端复刻版**。
零依赖、零构建，双击 `index.html` 即可运行；数据保存在浏览器 `localStorage`。

---

## 运行

- 直接双击 `index.html`（Chrome / Edge 均可）。
- 如需用手机同尺寸预览：`python -m http.server 8123 --directory .` 后访问 `http://127.0.0.1:8123/index.html`。

## 还原依据与已知取舍

- 配色取自录屏逐像素采样：主色 `#72B7D2`，分类睡觉/工作/学习/吃饭/运动/休息/其他 = `#72B7D2 / #F29374 / #F7D77C / #69DAC2 / #EC7C88 / #83AADD / #C3C3C4`。
- 汇总口径按视频反推：`未记录 = 已过分钟 − 已记录`，`今日剩余 = 1440 − 当前分钟`，百分比以 1440 为分母（14:55 时 62.1% + 37.9% = 100%）。
- **录屏全程为空数据**，因此「有数据」形态（记录行、目标卡片、统计指标、图表色块）是按 App 教程页文案与截图推演的合理实现。
- 习惯/我的宫格图标：源 App 为手绘插画，本复刻用同语义 emoji 呈现（保留圆底 + 分类配色），未做逐像素重绘。
- 「日程」「年视图」「睡眠统计」在录屏中未展开，按 App 常规形态实现。
