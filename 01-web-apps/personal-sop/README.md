# 个人工作台 · 学习生活 SOP

一个**纯前端、单文件、离线可用**的个人学习/生活/工作台。打开即用，数据全部保存在你自己的浏览器本地（localStorage），不上传任何服务器。

## ✨ 功能

- **今日**：日期/周次自动计算，今日课程、空闲时间安排一目了然
- **总课表**：周课表可视化，调课一处改、全局同步，空闲时段自动识别
- **专注计时**：番茄钟式学习专注记录
- **时间管理**：待办计划，掌控每天节奏
- **习惯打卡**：培养习惯，逐日追踪
- **购物库**：好物/品牌/渠道/价格记录，回购不踩坑（分类可增删）
- **记账**：收支记录 + 分类饼图 + 月汇总
- **阅读清单 / 考试倒数 / 健康管理**：学习生活全覆盖
- **数据中心**：一键导出/导入全部数据，换设备迁移无忧

## 🚀 使用

直接打开 [线上版本](https://fish1544.github.io/project/01-web-apps/personal-sop/) 或下载 `index.html` 双击用浏览器打开。

> 所有数据存于浏览器本地，不同浏览器/设备数据互不相通；换设备用「数据中心 → 导出/导入」迁移。

## 🛠 技术

- 原生 HTML / CSS / JavaScript，零依赖、零构建
- 单文件自包含，可离线运行
- 数据本地存储（localStorage），无后端、无隐私上传

## 📦 本地运行

```bash
# 无需安装任何东西
start index.html
```
