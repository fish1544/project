# 小小便利店 · 模拟经营

一款可发行、精美的手持模拟经营小游戏：经营你的便利店，进货、定价、雇佣员工、扩建店铺、应对天气与随机事件，打出属于你的便利店帝国。

## ✨ 特性

- 🎨 **原创矢量 + AI 插画**：商品/UI 矢量绘制全内置，背景与角色为原创 Q 版治愈系插画
- 🏪 **店铺扩建系统**：路边小店 → 社区便利店 → 人气商店 → 旗舰超市（货架 3→9 个，租金/客流/库存随等级成长）
- 💰 **精密经济**：定价影响顾客满意度与营收、顾客预算上限、每日租金/滞销损耗、贷款周转（日供 22%）
- 👥 **顾客类型化**：学生/上班族/老主顾/家庭客，各有偏好时段与商品；VIP 大客户随机出没
- 🎯 **每日目标 ×3 + 奖金**、⚡ **决策事件卡**（供应商涨价/小偷/卫生检查/博主探店/停电，二选一）
- 📈 **玩家等级/经验**：经营累积升级，库存上限成长
- 🌦 **动态世界**：天气系统（晴天/雨天/大风）、限时折扣、新品上市、周末促销等随机事件
- 🧑🍳 **员工系统**：收银员 / 理货员 / 清洁员，提效增收
- 📱 **双端适配 + PWA**：手机竖屏/桌面横屏自适应；可安装到桌面、离线游玩
- 💾 **自动存档**：本地 localStorage，旧版本存档自动兼容迁移

## 🎮 玩法

- **空格**：暂停 / 继续；**1 / 2 / 4**：切换游戏速度；**Esc**：关闭弹窗
- **点击货架 / 顾客**：查看详情、补货、改价
- **定价技巧**：进价 ×2.2 附近需求最好，太贵顾客扭头就走
- **扩建与贷款**：升级页扩建店铺；目标页可借款应急
- 目标是让顾客满意、声望提升、现金增长——别忘了打烊结算！

## 🚀 运行

直接打开 `index.html` 即可游玩（无构建、无依赖、文件夹自包含、可离线）。

在线试玩：<https://fish1544.github.io/mini-mart/>

## 📁 结构

```
mini-mart/
├── index.html             # 游戏入口（Canvas 单页应用）
├── manifest.webmanifest   # PWA 清单（可安装）
├── sw.js                  # Service Worker（离线缓存）
├── icon-192.png / icon-512.png
└── assets/                # AI 插画素材（背景 / 商品 / 顾客 / 员工）
```

## 🛠 技术

- 原生 HTML + Canvas + JavaScript，零依赖
- 响应式 CSS（媒体查询 + aspect-ratio），390px 竖屏 / 1280px 横屏均通过实测
- PWA：manifest + Service Worker，可安装、离线可玩
